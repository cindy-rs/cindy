# [Cindy](https://cindy.rs) — framework library

The library a cindy playbook depends on: the `#[cindy::main]` /
`#[cindy::remote]` / `#[cindy::inventory]` entry points, converged-state
builtins, sealed secrets, and the orchestrator/worker runtime.

You almost certainly want the CLI instead — `cargo install cindy-cli` —
which compiles and drives your playbook.
