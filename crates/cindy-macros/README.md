# cindy-macros

Procedural macros for the [cindy](https://crates.io/crates/cindy)
infrastructure management framework — `#[cindy::main]`,
`#[cindy::inventory]`, `#[cindy::remote]`, `#[cindy::action]`,
`#[cindy::wire]`, and `secret!`. An implementation detail of `cindy`:
depend on `cindy` and these come along.

[![crates.io](https://img.shields.io/crates/v/cindy-macros.svg?logo=rust&color=e6731b)](https://crates.io/crates/cindy-macros)

Developed in the [cindy monorepo](https://github.com/cindy-rs/cindy);
documentation at [cindy.rs](https://cindy.rs).
